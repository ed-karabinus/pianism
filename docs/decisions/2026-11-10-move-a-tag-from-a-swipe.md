# Move puts a piece or skill inside another, or back at the top level

Settled on 2026-11-09 (D4, the nested-tags plan, #224); the swipe's side and the screen are the owner's picks of
2026-11-10.

Swiping a piece or skill right shows Move, next to Add Inside, on any tag of the user's own with nothing inside it.
Built-in skills never move, as they can't sit inside anything. Move opens a screen titled "Move “D minor”", quoted like
Merge's: first a "Top level" row, then the pieces or skills it can go inside, under "Inside a piece" or "Inside a
skill": the top-level ones of its kind that aren't archived, built-in skills included. Where it is now is checked, and
choosing it changes nothing. Its sessions go with it, and none of them is rewritten.

Once it moves inside a tag, that tag unfolds, so the moved one stays in view. A tag the session had chosen stays
chosen, as the move changes only where it reads (the owner's pick 2026-11-10).

**Why:** the leading side holds what nests a tag, and a separate first row keeps "Top level" from being mistaken for a
tag of that name. A tag with something inside it would take that to a second level, so it doesn't move.
