# A piece or skill inside another reads "Parent › child"

Settled on 2026-11-09 (D5, the nested-tags plan, #224).

Wherever a session's tags are listed, on Practice's tag button, History's rows, the session editor and the CSV export,
a tag inside another reads with its parent first, "Scales › D minor". A tag at the top level reads as its own name.

**Why:** two lists can each hold a "D minor", so the name alone doesn't say which one a session has.
