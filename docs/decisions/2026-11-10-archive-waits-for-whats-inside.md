# A piece or skill can't be archived while something inside it isn't

Settled on 2026-11-09 (D1, the nested-tags plan, #224).

Archiving a piece or skill with unarchived tags inside it doesn't archive it. An alert says what to do first:
"Archive the 3 pieces inside “Études, Op. 10” first." Tags inside it that are already archived don't count.

**Why:** an archived tag then never has anything live inside it, so no screen needs a way to show one, and a tag still
being practiced never disappears with its parent.
