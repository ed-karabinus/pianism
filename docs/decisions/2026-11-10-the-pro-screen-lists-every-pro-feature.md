# The Pro screen lists every Pro feature

Settled on 2026-11-10, the owner's pick.

Under Included, the Pro screen has a line for each Pro feature, saying in a short sentence what it gives, with the
icon the feature uses elsewhere: piano sessions that start, pause and save themselves while Pianism is open; time per
piece and skill, in all and over the last 30 days; and exporting every session as a spreadsheet file (CSV). A new Pro
feature adds its line in the same pull request, and the Pro screen's end-to-end test checks for it.

**Why:** time per piece and export shipped without their lines, so someone deciding whether to buy saw a third of what
they'd get. Found while buying Pro on the first TestFlight build with it (S1). The owner picked a sentence for each over
the features' bare names, matching the piano line.
