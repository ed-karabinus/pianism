# The week unfolds what's inside a piece or skill

Settled on 2026-11-11, the owner's pick. It adds to D7 of [the nested-tags plan](../plans/plan-nested-tags.md), which
still holds: the week lists top-level pieces and skills, each with what's inside it rolled into its time.

In History's weekly "By piece and skill", a piece or skill with time this week from a tag inside it has a disclosure
arrow, folded at first, like the tag picker's. Unfolded, each tag inside it with time this week shows under it, by its
own name rather than "Scales › D minor", with its own time, longest first. A tag inside with no time this week isn't
listed. It's free, like the rest of the week.

**Why:** the owner expected the picker's arrow there after using nested skills on their iPhone. The week shows only this
week's time, so Time per piece and skill (Pro) still has more: every tag inside, all time and the last 30 days.
