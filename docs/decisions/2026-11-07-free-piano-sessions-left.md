# Practice counts down the free piano sessions

Settled on 2026-11-07, the owner's pick (D6 in `docs/plans/plan-pro.md`).

Without Pro, with a piano connected and no session, Practice says how many free piano sessions are left ("1 free
piano session left"). Once they're used, it says "Sessions that start themselves are part of Pro." with a Pianism Pro
link to the Pro screen. No pop-up. Tapping Start is always free, and a piano session already started plays on.

**Why:** it warns before auto-start stops and never interrupts practice.
