# The tag picker folds what's inside a piece or skill under it

Settled on 2026-11-09 (D3, the nested-tags plan, #224); the Add inside alert and the swipe's side are the owner's picks
of 2026-11-10.

In the tag picker, a piece or skill with something inside it has a disclosure arrow, folded unless one of the tags
inside it was chosen when the picker opened. The arrow folds and unfolds it; tapping its name tags it, as before. Open,
it ends with an "Add inside Scales" row. A search lists every match on its own, one inside another as
"Scales › D minor".

Swiping a top-level piece or skill right, built-in skills included, shows Add Inside. It and the row ask for the name
in an alert titled "New skill inside Scales" (or "New piece inside …"), with Cancel and Add, like Rename. A tag inside
another has no Add Inside: tags nest one level deep. Swiping left still shows Archive, Rename, Merge and Details.

A tag added inside another is tagged on the session, as a top-level add already is, and its parent unfolds to show it
(the owner's pick 2026-11-10).

**Why:** the lists stay as short as before nesting, a chosen tag is never hidden, and a search tells two tags of one
name apart. The leading side keeps what nests a tag apart from what changes it, and leaves room for Move. A tag
added now is usually being practised now, and an open parent shows where it went.
