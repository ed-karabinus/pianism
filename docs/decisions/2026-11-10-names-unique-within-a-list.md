# Names are unique within each list of pieces or skills

Settled on 2026-11-09 (Q1, the nested-tags plan, #224).

Adding or renaming a piece or skill refuses a name already in the same list: the top level, built-in skills included,
or the tags inside one parent. Case and accents don't count, as before. The same name can be in two lists, so
"Scales › D minor" and "Arpeggios › D minor" can both exist.

A piece or skill also can't share the name of the one it's inside, so "Scales › Scales" is refused, whether by adding,
renaming the one inside or renaming its parent (the owner's pick 2026-11-10).

**Why:** the parent's name tells them apart wherever they're shown, and a name like "D minor" belongs under several
skills. A tag named like the one it's inside reads like a mistake.
